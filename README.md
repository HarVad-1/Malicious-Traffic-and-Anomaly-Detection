# 🛡️ Snort IDS Web Interface with AI-Assisted Rule Generation and ML-Based Alert Classification
This project is an advanced intrusion detection system built on Snort IDS, integrated with a user-friendly web interface, an AI chatbot for rule creation, and machine learning models to reduce false positives. It aims to make network security more accessible for both experts and non-technical users.

🚀 Features
Web Dashboard
Intuitive UI to start and stop Snort-based attack monitoring on the local machine.

AI Chatbot for Rule Creation
Uses NLP to help users — even without technical knowledge — generate effective Snort rules through conversation.

Manual Rule Support
Power users can also define custom Snort rules directly.

Real-Time Malicious Log Display
Once monitoring begins, all detected malicious logs are displayed dynamically on the website.

Monitoring Control
Users can start/stop the IDS monitoring process with a single click.

Automated Report Generation
Generate comprehensive reports after each monitoring session, summarizing threats and statistics.

False Positive Reduction via ML
Two high-accuracy machine learning classification models are integrated to reduce false positives in Snort alerts.
